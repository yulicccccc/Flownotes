# FlowNotes — 空间自由思维沙盘与动态脑图系统 (v3.0.0)

## Goal
A full-featured Spatial Sensemaking & Dynamic Mindmap personal knowledge system (FlowNotes) deployed on Cloudflare Pages, replacing OneNote and XMind for non-linear spatial thinking without Microsoft account lock-in. Supports freeform 2D spatial dumping ("放到一坨"), direct on-canvas rich text cards (inline 🔴 red, 🟢 green, 🟡 yellow highlight, and 📸 screenshots), sticky tracking directional arrow links (`Tab` child, `Enter` sibling, drag-to-connect, and `L` key with "默认先 make 的是父"), mindmap fold/unfold on arrow-connected nodes, GitHub Gist anti-loss version control, and automated one-way sync to Obsidian.

## Finalized & Locked Features
- **Full OneNote + XMind Muscle-Memory Intuitive Suite (v3.0.0 集齐 OneNote + XMind 全套直觉操作)**:
  - **XMind Subtree Dragging (`collectSubtreeNodeIds`)**: Dragging any parent card automatically moves all of its connected children/descendants together as a unified branch! Holding `Alt + Drag` moves only the single card (or triggers proximity reparenting).
  - **OneNote Click-Anywhere-and-Type on Empty Canvas**: Clicking any empty spot on the canvas and immediately typing on the keyboard spawns a new freeform card right at that cursor spot (`lastCanvasMouseCoords`) and types directly into it.
  - **OneNote Right-Edge Card & Image Width Resize Handle (`.card-resize-handle`, `d.customWidth`)**: Every card and pasted screenshot has a draggable right-edge resize handle (`96px` to `680px`; double-click handle to reset to auto-width).
  - **OneNote Interactive To-Do Checkboxes (`Ctrl + 1`, `- [ ]` / `- [x]`, `.canvas-todo-checkbox`)**: Pressing `Ctrl + 1` (or clicking `☑` in the selection bubble / context menu) toggles To-Do checkboxes that can be checked/unchecked with a single click directly on the canvas card.
  - **XMind / Miro Relationship Labels on Arrows (`✏️ 写关系词` & Double-Click Arrow)**: Double-clicking any arrow or clicking `✏️ 写关系词` in `#link-action-bar` adds a relationship pill badge (`<g class="link-label-layer">`, e.g., `导致`, `抑制`, `混杂变量`) at the midpoint of the arrow that moves automatically when cards are dragged.
  - **XMind `Shift + Tab` Node Promotion (`promoteSelectedNode`) & `Space` Tap-to-Edit**: Pressing `Shift + Tab` promotes a child card up one level; tapping `Space` on a selected card opens inline editing (while holding `Space + Drag` pans the canvas).
  - **2D Spatial + Tree Arrow-Key Navigation (`navigateNodes`)**: Arrow keys (`↑` `↓` `←` `→`) unfold collapsed branches on `→`, navigate tree links in tree mode, and jump to the nearest card in the 2D directional cone in freeform mode.
  - **Expanded Selection Quick Bubble (`🔴` `🟢` `🟡` `B` `U` `☑` `🧹`)**: Added Bold (`B`), Underline (`U`), and To-Do (`☑`) directly into `#selection-quick-bubble`.
- **Intuitive Direct-Manipulation Interaction Suite (v2.9.0 直觉式框选、多选浮动工具栏、箭头点击反转/删除与右键菜单)**:
  - **Default Left-Mouse Drag Rubber-Band Selection (`isMarqueeMode = true` by default)**: Dragging with the left mouse button on empty canvas immediately draws a selection box (`#marquee-box`) with true AABB rectangle intersection (touching any card edge selects it; shrinking the box deselects it). Clicking empty canvas immediately deselects all cards/arrows. Canvas panning works smoothly via mouse wheel / two-finger scroll, `Space + Left Drag`, middle-mouse drag, or toggling `✋/🔳`.
  - **Fixed `Shift + Click` Multi-Selection**: Fixed `dragstarted` so `mousedown` never wipes `selectedNodeIds` when `Shift`/`Ctrl`/`☑️` is active.
  - **Floating Multi-Select Action Bar (`#multi-select-action-bar`)**: Automatically appears right above the selection when 2+ cards are selected, offering 1-click **`➔ 连箭头 (先建为父)`**, **`⛓️ 顺序串联`**, **`📐 垂直排齐`**, **`📐 水平排齐`**, **`⭐ 重点`**, **`🧬 克隆`**, and **`🗑️ 删除`**.
  - **Clickable Arrows & Floating Arrow Action Bar (`#link-action-bar`)**: Clicking any arrow highlights it and pops up **`⇄ 反转父子方向`** and **`✂️ 删除此箭头 (Del)`** (deletes only the arrow while keeping the cards).
  - **OneNote-Style Click-Selected-Card-to-Edit & `+` Quick-Sprout Button**: Clicking an already-selected card enters inline text editing; every card also shows a green `+` button on its right edge to sprout a child card with 1 mouse click.
  - **Right-Click Context Menu (`#canvas-context-menu`) & Clipboard (`Ctrl+A`, `Ctrl+C`, `Ctrl+V`, `Ctrl+D`)**: Full desktop context menu on both cards and empty canvas, plus card copy/paste/duplicate.
- **PWA Standalone App, High-Capacity IndexedDB & Multi-Device Auto-Sync (v2.8.0 独立桌面应用、无限图片容量与多端无感同步)**:
  - **PWA Standalone Mode (`public/manifest.json` + `public/sw.js`)**: Supports 1-click installation to Windows/macOS Desktop & Taskbar or iOS/Android Home Screen (`#btnInstallPwa`), with Network-First offline Service Worker caching so it opens instantaneously anywhere, online or offline.
  - **High-Capacity `IndexedDB` Storage (`FlowNotesIDB` + `safeLocalStorageSet`)**: Breaks through browser `localStorage`'s 5MB limit by persisting the full multi-map bundle (`flownotes_full_bundle`) in `IndexedDB` + in-memory cache (`allMapsMemoryCache`), allowing hundreds of MBs of screenshots without `QuotaExceededError`.
  - **Multi-Device Bi-Directional Cloud Auto-Check (`autoCheckCloudGist` + `flushPendingSave`)**: Automatically flushes any pending debounced edits on `beforeunload`/`pagehide`/`visibilitychange`, and checks GitHub Gist on startup & window focus to auto-pull newer cloud commits from other devices when local has no conflicting unsynced edits.Also wired up bottom-left `#btn-sync` (`💾 同步`), `#btn-pull` (`↙️ 拉取`), and `#btn-import` (`⬆️ 导入 JSON`).
  - **Zero-Latency Touch & Non-Touch Experience**: Eliminates the 300ms mobile tap delay via `touch-action: none`, adds `< 320ms` fast double-tap on cards/canvas for touchscreens, and adds `+子` (`#btn-add-child`), `+同` (`#btn-add-sibling`), and `☑️` (`#btn-multi-select`) buttons so touch/mouse-only users can create child/sibling cards and multi-select cards to connect foldable arrows ("默认先 make 的是父") without needing a physical keyboard.
- **Freeform Spatial Canvas & Direct Rich-Text Card Rendering (v2.7.0 自由空间“放到一坨”与画布富文本直显)**:
  - **Freeform Spatial Dumping (`layoutMode = "free"` by default)**: Double-clicking or pasting (`Ctrl+V`) places independent cards at exact 2D cursor coordinates (`fx/fy`) without forcibly snapping unrelated notes into a vertical tree column. Unrelated thoughts can sit side-by-side in clusters ("放到一坨") without accidental auto-reparenting (`Alt + Drag` required for proximity drop reparenting).
  - **Direct On-Canvas Rich Sentences & Image Cards (`<foreignObject class="node-card-fo">`)**: Sentences on the canvas directly display inline 🔴 red words, 🟢 green words, 🟡 yellow `<mark>` highlights, multi-line text, and 📸 pasted screenshots—just like OneNote, without needing to look at the right sidebar.
  - **Direct On-Canvas Inline Editing & Selection Bubble**: Double-clicking any text card edits it directly on the canvas (`contenteditable="true"`). Selecting words directly inside a canvas card pops up `#selection-quick-bubble` (`[🔴] [🟢] [🟡] [🧹]`) right above the card on the canvas.
- **Sticky Tracking Arrows & "默认先 make 的是父" Foldable Connections (v2.6.0 - v2.7.0)**:
  - **Dynamic Rectangle-Edge Directional Arrows (物理有向箭头矩形边界精确止步与跟随)**: Uses ray-rectangle intersection (`getRectEdgePoint`) with dynamically measured card width/height (`_cardW`, `_cardH`) so SVG arrowheads (`#arrow-marker`) start at the parent card's outer border and stop cleanly at the child card's outer border at any 360° angle. Moving any card stretches, shrinks, and rotates connected arrows in real time.
  - **Keep `Tab` (Child) & `Enter` (Sibling) Shortcuts**: Pressing `Tab` sprouts a connected child card (`Parent ➔ Child`) with automatic vertical offset so siblings don't overlap; pressing `Enter` sprouts a sibling card.
  - **"默认先 make 的是父" (Earlier-Created Card = Parent) When Connecting Existing Cards**:
    - Every card records its creation timestamp (`createdAt`).
    - Multi-selecting 2+ existing cards (`Shift+Click` or `Shift+Drag` / `B` marquee box) and pressing `L` (or clicking `➔` `#btn-relation`) sorts the selected cards by `getNodeCreatedTime(node)` ascending: **the card created (`make`) earlier automatically becomes the Parent (`Parent ➔ Child`), and the later-created card(s) become its Children**.
    - Every card also provides a right-edge `.node-connect-port` (`➔` handle) to drag a directional arrow directly from one card to another with the mouse.
  - **Mindmap Fold/Unfold on All Arrow-Connected Cards**: Any card with outgoing parent-child arrow(s) displays a fold/unfold badge (`−` / `+N`) on its right edge (and supports `Ctrl + /`, `Ctrl + ←`, `Ctrl + →`), collapsing or expanding all downstream arrow-connected descendants like a mindmap.
- **Zero-Friction Colors & Highlighting (v2.6.0 - v2.7.0 零摩擦高频标注套件)**:
  - **Keyboard Stream (盲打式全键盘流)**:
    - `Ctrl + Shift + R`: 🔴 瞬间标红 (核心科学问题 / 重点自变量)
    - `Ctrl + Shift + G`: 🟢 瞬间标绿 (测量指标 / 因变量 / 关键特征)
    - `Ctrl + Shift + H`: 🟡 瞬间荧光黄高亮 (`==highlight==` / `<mark>`)
    - `Ctrl + Shift + \`: 🧹 瞬间清除格式与列表
  - **Selection Quick Bubble (`#selection-quick-bubble`)**: Mounted on `document.body` so it works both inside on-canvas cards (even when the right sidebar is collapsed) and inside `#rich-editor`.
  - **Format Toolbar Presets**: Dedicated 1-click preset buttons on the editor toolbar (`🔴 红`, `🟢 绿`, `🟡 亮`, `🧹 擦除`).
- **Smooth Zero-Lag Input & IME Protection (v2.7.0 输入防抖与输入法防卡顿)**:
  - Debounced storage persistence (`scheduleSaveGraph`, 360ms) + Chinese IME `compositionstart`/`compositionend` guards eliminate synchronous `JSON.stringify` / `localStorage` / DOM rebuild stalls during fast typing or handwriting input.
- **Global Clipboard Image & Text Paste (v2.6.0 - v2.7.0 剪贴板直贴画布)**:
  - **Screenshot Direct Paste**: Press `Ctrl + V` anywhere on the canvas with screenshot/image data in the clipboard (`Win + Shift + S`) to spawn an independent floating image card at the exact cursor position (without camera jump), auto-compressed via HTML5 Canvas (`max 1000px`, `0.85` JPEG quality).
