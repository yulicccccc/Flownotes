# FlowNotes to Obsidian Sync

## Goal
A script to sync web-based graph relationships from FlowNotes (JSON) to Obsidian's file system (Markdown).

## Finalized & Locked Features
- Manual export from FlowNotes Web to JSON.
- Automated PowerShell script `sync_to_obsidian.ps1` to parse JSON and map to Markdown.
- One-way sync to local Obsidian vault.
- Filenames cleaned to be Windows-compatible.
